⏱️ Non-Blocking Asynchronous Sequence Flow

sequenceDiagram
    autonumber
    actor Client as User / REST Client
    participant API as FastAPI Orchestrator (app/api/drugs.py)
    participant Cache as Local SQLite Cache
    participant FDA as 🇺🇸 US FDA SrLC
    participant HC as 🍁 Health Canada
    participant TGA as 🇦🇺 Australia TGA
    participant MW as 🚨 FDA MedWatch
    participant MHRA as 🇬🇧 UK MHRA
    participant DB as SQLite (medicine_safety.db)

    Client->>API: GET /api/drugs/search?q=Ozempic&source=ALL
    API->>Cache: Query cached entries for 'Ozempic' across all 5 authorities

    alt All Sources Cached and Fresh (<24h TTL)
        Cache-->>API: Return cached records for all 5 authorities
        API-->>Client: 200 OK (Instant JSON Response in <15ms)
    else Cache Miss or Partial
        par Concurrent Live Crawling (asyncio.gather)
            API->>FDA: Async crawl accessdata.fda.gov (POST ViewState)
            API->>HC: Async query health-products.canada.ca (DPD + InfoWatch)
            API->>TGA: Async search tga.gov.au/search?keywords=Ozempic
            API->>MW: Async query openFDA FAERS API & RSS feeds
            API->>MHRA: Async query gov.uk/drug-safety-update.json
        end

        par Parallel Response Parsing & Normalization
            FDA-->>API: 200 OK: NDA-209637, 27 Safety Changes
            HC-->>API: 200 OK: DIN 02471469, 7 Safety Advisories
            TGA-->>API: 200 OK: AUST R 308323, 3 PI Leaflets & Alerts
            MW-->>API: 200 OK: MW-FAERS-209637, 7 Adverse Event Signals
            MHRA-->>API: 200 OK: PLGB 16950/0333, 5 Drug Safety Updates
        end

        API->>DB: Begin Database Transaction
        API->>DB: Upsert 'drugs' rows (scoped by source + drug_name)
        API->>DB: Insert 'safety_labeling_changes' (warnings, clinical advice)
        API->>DB: Compute SHA-256 and archive new 'safety_change_versions'
        DB-->>API: Commit Transaction
        
        API-->>Client: 200 OK: Consolidated 5-authority JSON payload
    end

🏛️ Detailed Breakdown of All 5 Website Data Sources

🇺🇸 US FDA SrLC
Drugs@FDA & SrLC
accessdata.fda.gov

Crawls ASPX form search results, maintains session ViewState, extracts approval dates, active ingredients, and parses Boxed Warnings and Adverse Reactions.

Key ID: NDA-XXXXXX / BLA-XXXXXX
🍁 Health Canada
DPD & InfoWatch
health-products.canada.ca

Queries Canada Drug Product Database (DPD) for active DINs, dosage forms, routes, Product Monograph links, and pairs with InfoWatch safety advisories.

Key ID: DIN XXXXXXXX
🇦🇺 Australia TGA
Therapeutic Goods Admin
tga.gov.au/search

Crawls TGA search portal with Akamai-resilient browser headers, extracts registered goods, sponsor information, and Australian Product Information (PI/CMI).

Key ID: AUST R / AUST L
🚨 FDA MedWatch
MedWatch & FAERS
fda.gov/safety/medwatch

Ingests live MedWatch Safety Alerts RSS feed, queries openFDA FAERS adverse drug reaction endpoints, tracks Class I/II recalls, and links to Form 3500.

Key ID: MW-FAERS-XXXXXX
🇬🇧 UK MHRA
Drug Safety Update
gov.uk/drug-safety-update

Queries live GOV.UK JSON search endpoint and ATOM feed for monthly bulletins, extracts UK Product Licences (PL/PLGB), and links to Yellow Card reporting.

Key ID: PL / PLGB XXXXX/XXXX

💾 SQLite Relational Schema & Collision Prevention (Mermaid ERD)

erDiagram
    DRUGS ||--o{ SAFETY_LABELING_CHANGES : "has many"
    SAFETY_LABELING_CHANGES ||--o{ SAFETY_CHANGE_VERSIONS : "has audit history"

    DRUGS {
        int drug_id PK "Auto-increment primary key"
        string drug_name "Normalized Brand Name (e.g. OZEMPIC)"
        string active_ingredient "Normalized Active Substance (e.g. SEMAGLUTIDE)"
        string application_number "Authority ID (NDA, DIN, AUST R, MW-FAERS, PLGB)"
        string source "Source: FDA_SRLC, HEALTH_CANADA, AUSTRALIA_TGA, FDA_MEDWATCH, UK_MHRA"
        datetime created_at "Initial ingestion timestamp"
        datetime last_verified_at "Last checked timestamp"
    }

    SAFETY_LABELING_CHANGES {
        int change_id PK "Auto-increment primary key"
        int drug_id FK "References DRUGS(drug_id)"
        string section_name "e.g. BOXED WARNING, ADVERSE REACTIONS, CLINICAL ADVICE"
        string summary "Brief summary of warning or update"
        text description "Complete regulatory advisory text"
        datetime change_date "Publication or effective date"
        string content_hash "SHA-256 hash for revision tracking"
    }

    SAFETY_CHANGE_VERSIONS {
        int version_id PK "Auto-increment primary key"
        int change_id FK "References SAFETY_LABELING_CHANGES(change_id)"
        int version_number "Sequential revision (1, 2, 3...)"
        text previous_content "Historical advisory text"
        string previous_hash "Previous SHA-256 hash"
        datetime detected_at "Detection timestamp of modification"
    }
