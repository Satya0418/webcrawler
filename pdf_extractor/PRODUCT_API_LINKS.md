You **do not** need to type or remember long query URLs like `http://127.0.0.1:8000/api/v1/products/section-16?product_name=ofloxacin&subsection=16.1&format=html`.

Instead, use these ultra-clean short URLs directly in any web browser:

## 🔄 Automatic Link Creation for New PDFs

Whenever a new PDF is added:
1. Drop, copy, or upload it to:
   - `/Users/satya/Desktop/Medical/`
   - `pdf_extractor/watch_pdfs/`
   - `pdf_extractor/uploads/`
   - `webcrwler/backend/data/pdf_cache/`
2. The real-time filesystem watcher automatically extracts Section 16 within 2–3 seconds.
3. Its short link is immediately available at:
   ```text
   http://127.0.0.1:8000/p/<new_medicine_name>/16.1
   ```
4. It also automatically appears in the visual catalog at [http://127.0.0.1:8000/catalog](http://127.0.0.1:8000/catalog).
